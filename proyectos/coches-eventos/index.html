Coches para eventos

Web para alquilar coches clásicos y de lujo para bodas y eventos. Diseñé la web y creé con IA las fotos de los coches, porque moverlos para hacer una sesión era casi imposible.

RolDiseño web e imagen con IA

Contexto

El proyecto era una web para alquilar coches clásicos y de lujo para bodas y eventos. La web ya no está en línea, así que la maqueta que ves es una recreación de cómo era, hecha con las fotos originales.

Las fotos, con IA

Desplazar cada coche para hacerle una sesión de fotos era muy difícil, así que creé las imágenes con IA: cada coche en un escenario elegante, con una luz y un estilo comunes para toda la colección.

Resultado

Una colección de imágenes coherente para toda la flota, que hoy se sigue usando en la web de vehículos para eventos de Grupo Herme.
